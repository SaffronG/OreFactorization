# Vintage Story Improved Ore Processing

Author: SaffronG

## Features

- (WIP) Blast furnace with a Channel system for batch processing
  - Can be fed using the conveyor system
- (WIP) Conveyor belt system
  - Integrates cleanly with the base-game pipes and hoppers
- (WIP) Centrifuge for automated ore processing
  - Low tier, simply automates the hammer-based crushing process
  - Mid tier, has a 5% chance of generating another dust, and a 5% chance of producing a by-product
  - High tier, chances are increased to 10% for both
- (WIP) More efficient ore alloying and smelting
  - More alloys for improving recipe efficiencies
- (WIP) Added rotational power-based bellows and ore processing tooling
  - bellows
  - centrifuge tier 1, 2, and 3
  - sifter
  - crusher
  - washer
- (WIP) Added bessemer process for fast steel production
  - The bessemer boiler is an expensive multi-block structure
- (WIP) Add auto emptying casting molds
  - Gravity-based system where there are specialized molds that hold the ore until it is solidified enough
  - Have mold-holders so you can quick swap the molds on the channel
- (WIP) Add higher tier pipes so you can transport some molten metals
  - Have a pressurizing system that will add the required pressure to move the molten metal
